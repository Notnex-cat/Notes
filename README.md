# 📝 Notes — Android-приложение для создания и редактирования заметок

**Notes** — это Android-приложение, позволяющее пользователю создавать, редактировать и удалять текстовые заметки. Проект полностью реализован с использованием современных подходов и технологий Android-разработки.

---

## 🚀 Функциональность

- ✅ Добавление новой заметки
- 📝 Редактирование существующих заметок
- ❌ Удаление заметок
- 🔍 Поиск заметок по ключевым словам
- 🗃️ Сортировка по дате
- 🎨 Современный UI на Jetpack Compose

---

## 🧠 Архитектура и технологии

- **Jetpack Compose** — декларативный UI-фреймворк
- **MVVM** — Model-View-ViewModel
- **Room** — локальная база данных (SQLite ORM)
- **Kotlin** — основной язык проекта
- **Coroutines** — асинхронная работа с БД
- **Navigation Component** — управление экранами и back stack
